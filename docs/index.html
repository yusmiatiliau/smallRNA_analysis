smallRNA_analysis

Scripts for small RNA processing & analysis

This document records the tools and scripts I used for the small RNA analysis

Processing

Before the analysis, we did a few processing and filtering steps to remove non-relevant components such as adaptors, rRNA, tRNA, reads in low complexity regions,etc.

Trimgalore

trim_galore \
--small_rna \
--length 17 \
--output_dir /DIR_output \
--fastqc_args "--outdir /DIR_fastqc_output" \
--cores 4 \
--gzip \
--2colour 20 \
file.fq.gz

Prinseq

This is to remove low complexity reads. Output would be good.fq and bad.fq

zcat trimmed.fq.gz | \
prinseq-lite.pl \
-lc_method dust \
-lc_threshold 40 \
-fastq stdin

Remove tRNA and rRNA

For this, we first download the tRNA and rRNA sequences from Rfam database using esl-sfetch

esl-sfetch -h
esl-sfetch --index /home/cenliau/00_nesi_projects/brins03581_nobackup/Cen/Rfam.fa

Then use this perl script to extract the tRNA and rRNA sequences get_vitis_rfam.pl

chmod +x get_vitis_rfam.pl

cd /DIR
./get_vitis_rfam.pl
mkdir -p tRNA
mkdir -p rRNA

for file in /DIR/tRNA_RF*.txt
do
[ -e "$file" ] || continue \     
name=$(basename "$file" .txt) \     
esl-sfetch -f Rfam.fa "$file" \
> "/tRNA/${name}.fa"
done

for file in DIR/rRNA_RF*.txt
do    
[ -e "$file" ] || continue \
name=$(basename "$file" .txt) \
esl-sfetch -f Rfam.fa "$file" \
> "/rRNA/${name}.fa"
done

Next, concatenate all the sequences into single fasta file we can use for alignment

cat /tRNA/*.fa > trna_rfam.fa
cat /rRNa/*.fa > rrna_rfam.fa
cat trna_rfam.fa rrna_rfam.fa > tRNA_rRNA_rfam.fa

And lastly, we aligned our filtered reads to this rRNA_tRNA sequence, and use the unmapped reads for subsequent processing

#build bowtie2 index
bowtie2-build tRNA_rRNA_rfam.fa /ref/bowtie2-build_rfam

#alignment
ref_rfam=/DIR/bowtie2-build_rfam

cd $DIR/prinseq/good
for i in *_good.fastq
do
base=$(basename "$i" _good.fastq)
bowtie2 --threads 4 -x $ref_rfam -q $DIR/prinseq/good/${base}_good.fastq --local -N 0 -k 100 | samtools sort -@8 | samtools view -b -f 4 -@8 -o $DIR/bowtie2_rfam/${base}_rfam.unaligned.sorted.bam
samtools fastq -T '*' $DIR/bowtie2_rfam/${base}_rfam.unaligned.sorted.bam | gzip > $DIR/bowtie2_rfam/${base}_rfam.unaligned.fastq.gz
done

Analysis

There are two main analysis I did:

  1. Identify the mobile sRNA, i.e. smallRNA present in scion tissue (Sauvignon Blanc leaf) that presumed to be originated from the rootstock. To do this, we first align the reads to the scion genome (both haplotypes), take the unmapped reads and align to the respective rootstock genome (one haplotype).

  2. Analyse the association of smallRNA reads with drought stress. For this, we map the reads to a concatenated reference genome of the scion and rootstock, perform clustering (both done within ShortStack) and run differential analysis on the result to identify clusters that are significantly associated with drought stress.

Identify mobile sRNA

First, filtered small RNA reads were mapped to the scion genome using bowtie. the unmapped reads were used to map to the rootstock genome

#Create bowtie-index
bowtie-build SB2.1_diploid_plusorg.fasta SB2.1_bowtie_build/SB2.1_diploid


#Map to scion genome
cd $DIR/
for i in *_nonchloro_SB.fastq.gz
do
base=$(basename "$i" _nonchloro_SB.fastq.gz)
bowtie --threads 8 -v 0 -a -m 50 --best --strata \
       --un $DIR/${base}.unaligned.SB.fq \

       -S -x $ref_SB_hap1 \

#Map unmapped reads to rootstock genome (e.g. 3309)

Association of small RNA with drought stress

For this, we use small RNA mapped to both scion and rootstock. Mapping and clustering was done using ShortStack. Shortstack also use bowtie for mapping, but has default setting that allows 1 mismatch. We modify the script manually to change the mismatch allowed to 0, according to this thread: https://github.com/MikeAxtell/ShortStack/issues/177


#Mapping and clustering
ShortStack --bamfile file1.bam file2.bam ...filexx.bam \
--dicermin 20 --dicermax 24 --mincov 5 \
--genomefile ref_SB_3309.fa \
--known_miRNAs mirbase_vitis.fasta \
--outdir Result_DIR/

Differential analysis was done using Deseq2, using the count.txt table output of shorstack

#Diff analysis, example for siRNA 
count_mat <- round(as.matrix(counts_sirna)) 
coldata <- as.data.frame(coldata)

coldata$ctrl_stress <- as.integer(coldata$drought == "control" & coldata$timepoint == "stress")
coldata$trt_stress <- as.integer(coldata$drought == "treatment" & coldata$timepoint == "stress")

#paired Wald model 
#(trt stress - trt baseline) - (ctrl stress - ctrl baseline)
#Positive LFC = treatment has a more positive stress response

dds <- DESeqDataSetFromMatrix( 
  countData = count_mat, 
  colData = coldata, 
  design = ~ pair_id + ctrl_stress + trt_stress)

dds <- estimateSizeFactors(dds, type = "poscounts") 
sizeFactors(dds)
dds <- DESeq(dds) 
rn <- resultsNames(dds)

int_contrast <- setNames(rep(0, length(rn)), rn) 
int_contrast["trt_stress"] <- 1 
int_contrast["ctrl_stress"] <- -1

int_contrast

res_interaction <- results(dds, contrast = int_contrast) 
summary(res_interaction)

interaction_res <- as.data.frame(res_interaction) 
interaction_res$Name <- rownames(interaction_res)
interaction_res <- merge(interaction_res, locus_info, by = "Name", all.x = TRUE)
